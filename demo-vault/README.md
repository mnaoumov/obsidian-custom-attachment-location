# Custom Attachment Location demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Custom Attachment Location](https://github.com/mnaoumov/obsidian-custom-attachment-location) plugin.

## Opening this vault

- **If you already have the plugin installed on desktop**, run the **`Custom Attachment Location`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise, and always on mobile, where the command is not available**, download `obsidian-custom-attachment-location-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `obsidian-custom-attachment-location-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
