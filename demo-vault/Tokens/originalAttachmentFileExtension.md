# `{{originalAttachmentFileExtension}}`

Extension of the name the attachment arrived with, without its dot. Pairs with [`{{originalAttachmentFileName}}`](<./originalAttachmentFileName.md>), and falls back the same way. [`{{attachmentFileExtension}}`](<./attachmentFileExtension.md>) is the current one.

One of the tokens in [09 Token reference](<../09 Token reference.md>), which also covers the format syntax and validation every token shares.

## Format schema

*(No format for this token)*.

## Default (omitted) format

`null`.

## Examples

- `{{originalAttachmentFileExtension}}`: `alpha.bravo.pdf -> pdf`.
