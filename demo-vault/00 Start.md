Welcome to the [Custom Attachment Location](https://github.com/mnaoumov/obsidian-custom-attachment-location/) demo vault. When you paste or drag a file into a note, Obsidian normally drops it into one shared attachment folder with a generic name. **Custom Attachment Location** lets you decide *where* each attachment is stored and *how* it is named, using tokens like `${noteFileName}`, `${date:{momentJsFormat:'YYYYMMDD'}}`, and many more.

**How to try it:** open [[01 Attachment folder location]] and paste an image into it. With this vault's default settings, the file lands in a per-note folder such as `assets/01 Attachment folder location/` instead of one global pile. You supply the pasted or dragged file - the plugin decides where it goes and what it is called.

> [!TIP] Interactive buttons
>
> The two setup notes have **Run** buttons, powered by [`CodeScript Toolkit`](https://github.com/mnaoumov/obsidian-codescript-toolkit/), which this vault installs for you automatically on first open (see [[08 CodeScript Toolkit prerequisite]]). The feature itself is driven by pasting/dragging files and by the plugin's own commands, so the feature notes have no buttons.
